# 수주대토 (守株待兎)

그루터기를 지키며 토끼를 기다리는 도트 인크리멘탈 게임입니다.
지나가던 사람이 그루터기에 부딪힌 토끼를 주워 가는 걸 본 그날부터 기다리기 시작해, 복권방, 코인, 주식, 영상, 스타트업, 부동산, AI 대박을 거쳐 마지막엔 나 자신 앞에서까지 기다립니다. 장소마다 토끼(대박)는 딱 한 번 옵니다. 언제나 남에게.

**바로 플레이:** https://baramutzero-netizen.github.io/stumprabbit/

`index.html` 한 파일로 돌아갑니다. 내려받아 브라우저로 열어도 됩니다(그림, 소리, 글꼴이 모두 이 파일 안에 있음).

## 하는 법

- 현장 탭에서 "하루 더 기다리기"를 누르면(장면을 누르거나 스페이스바를 눌러도 됨) 하루가 지나고 **기다린 날**이 쌓입니다.
- 장소마다 한 번은 황금 토끼가 달려와 부딪힙니다. 그리고 낯선 사람이 와서 주워 갑니다(옆 사람 1등 당첨, "코인으로 100억" 뉴스, 김 대리 종목 상한가, 남의 영상 100만…). 그걸 보고 나도 기다리기 시작합니다. 그 뒤로 오는 토끼는 바로 앞에서 돌아서 갑니다("번호 하나 차이!", "검토 후 연락드릴게요").
- 뒤쪽 밭은 기다릴수록 잡초가 자라고, 옆집 이웃은 그동안 꾸준히 수확합니다.
- 기다림도 탭의 노드 트리에서 기다린 날로 "더 잘 기다리는 법"을 삽니다. 수는 네 가지입니다.
  - 배수: 더 큰 그루터기, 존버, 김 대리 종목 따라 사기, 뜬 영상 따라 찍기, 대박 앱 프롬프트 따라 하기…
  - 같이 기다리는 사람
  - 대신 기다려 주는 것: 허수아비, 자동 매매 봇, AI 에이전트…
  - 악단
- 모든 수를 산 뒤 **일어나기**를 사면 엔딩이 나옵니다. 한 판은 5분 남짓 걸립니다.

## 담긴 것

| 장소 | 기다리는 것 | 같이 기다리는 사람 |
| --- | --- | --- |
| 밭 그루터기 | 토끼 | 동네 사람들, 동네 아이들 |
| 복권방 | 1등 | 단골들, 명당 대기 줄 |
| 코인 | 떡상 | 코인 단톡방, 코인 유튜버 |
| 주식 | 상한가 | 개미들, 증권 방송 |
| 영상 | 알고리즘 | 구독자들, 댓글러 |
| 스타트업 | 다음 투자 | 공동 창업자들, VC들 |
| 부동산 | 재개발 | 동네 주민들, 중개업자들 |
| AI 대박 | 대박 앱 | 베타 사용자들, AI 인플루언서 |
| 나 자신 | 운 | 내 안의 목소리, 어린 시절의 나 |

- **악단:** 장소마다 다섯 파트가 있고, 앞 장소의 악단도 같은 볼륨으로 계속 연주합니다(풀벌레부터 새벽 현악까지 45파트). 파트마다 크기를 재서 고르게 맞췄습니다(`tools/measure_band.js`).
- **엔딩:** 내 토끼는 끝내 오지 않고, 그루터기는 명소가 되어 사람들이 줄을 서서 기다립니다. 나는 처음으로 일어나 밭을 갑니다.
- **기다림 보고서:** 결과 카드를 PNG로 저장하거나 공유할 수 있고, 다른 게임도 추천합니다.

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 완성된 게임 한 파일 |
| `game.src.html` | 게임 소스(글꼴과 그림이 들어갈 자리가 비어 있음) |
| `assets/aseprite/`, `assets/png/` | 도트 원본 `.aseprite` 파일과 4배 크기 PNG |
| `tools/sprites.py` | 모든 도트의 원본 데이터. `sprites.json`, `.aseprite`, PNG를 만듦 |
| `tools/build.py` | 쓰는 글자만 잘라 글꼴을 넣고 `index.html`을 만듦 |
| `tools/measure_band.js` | 악단 파트별 크기 측정 |

## 다시 빌드하기

```bash
pip install pillow fonttools brotli
cd tools && python3 sprites.py && cd ..
GALMURI=경로/package/dist python3 tools/build.py
```

## 만든 것과 빌린 것

- 도트 그림은 모두 직접 그렸고, 소리는 모두 브라우저에서 실시간으로 합성합니다. 게임 속 인물, 종목, 장소는 모두 지어낸 것입니다.
- 글꼴은 [갈무리(Galmuri)](https://github.com/quiple/galmuri)를 썼습니다(© Lee Minseo, SIL Open Font License 1.1). 게임에 쓰는 글자만 잘라 넣었고, 라이선스 전문은 `fonts/Galmuri-OFL.txt`에 있습니다.
- 진행 기록은 브라우저(localStorage)에만 저장되고 어디로도 보내지 않습니다.
